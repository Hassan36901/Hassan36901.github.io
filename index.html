Troubleshooting examples

Common service desk problems and how I would work through them. Select a problem to see my approach.

User is locked out or has forgotten their password
Approach
  1. Verify the user's identity using the company's process.
  2. Find the account in Active Directory and check whether it is locked, disabled or expired.
  3. Unlock the account or reset the password and set it to change at next login.
  4. Ask the user to log in while I stay on the line to confirm it works.
  5. Log the cause and the fix in the ticket.
Escalate ifthe account keeps locking. This can point to a saved old password on another device or a security issue.
Computer has no internet connection
Approach
  1. Check whether it is one device or several, and whether it is Wi-Fi or a cable.
  2. Check the basics: Wi-Fi switched on, flight mode off, cable plugged in.
  3. Restart the network adapter, then the computer.
  4. Check the device has a valid IP address and can reach the router.
  5. If other devices are affected too, check the router or switch and report a network issue.
Escalate ifseveral users are offline. That is likely a network incident for the network team.
Computer is running slowly
Approach
  1. Ask when it started and whether anything changed, such as new software or updates.
  2. Open Task Manager and check CPU, memory and disk usage for a program using too much.
  3. Close or remove the problem program and review startup apps.
  4. Check free disk space and pending updates.
  5. Restart and test. Run a malware scan if the cause is unclear.
Escalate ifthe disk or memory looks faulty, or the device is too old for its workload.
Printer is not printing
Approach
  1. Check the printer for power, paper, toner and error lights.
  2. Check it is online and that the user chose the right printer.
  3. Clear the print queue and try a test page.
  4. Restart the print spooler and, if needed, reinstall the driver.
  5. Try printing from another computer to tell a user fault from a printer fault.
Escalate ifthe printer shows a hardware fault or nobody can print to it.
User reports a suspicious email
Approach
  1. Tell the user not to click links or open attachments, and not to reply.
  2. Ask whether they already clicked or entered any details.
  3. Report the email through the company's security process and keep the original.
  4. If they entered a password, reset it straight away and escalate as a security incident.
Escalate ifany link was clicked or any details were entered.
